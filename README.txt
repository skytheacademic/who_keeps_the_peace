Reproducibility
	- Scripts were run under R 4.6.0. Packages are loaded with groundhog (pinned to groundhog.day = "2026-06-01")
	  so the same package versions are used on any machine. Run the scripts from the repo root, in order:
	  clean_data.R -> match_data.R -> analyze_data.R.

R Scripts (main = replication package)
	- clean_data.R contains all code to clean and prepare data for analysis
	- match_data.R contains all code to match data for the main paper, as well as code for the matching loveplot
	  (Figure, Appendix) and matching for the cutoff robustness in the Appendix.
	- analyze_data.R contains all code to run every model in the paper and to write every table and figure it owns.
	  It is organized to follow the order of the paper: the descriptive map (map_prop), the main-text tables and
	  2SLS / matched-odds-ratio figures, then the appendix tables and cutoff-robustness figures. Each output is
	  tagged in-line with its LaTeX label (e.g. tab:hyp_1, fig:match).

Job-talk figures (on the `job-talk` branch)
	- The presentation figures (DRC map suite, WPS timeline, marginal-effects plots, descriptive women/men maps,
	  female-PK ridgelines, and the matched-prediction variants) are generated by make_slides.R, which lives only on
	  the `job-talk` branch. The original interactive and iterative code, plot_data.R, also lives on that branch.

UCDP data
	- Contains violence data from the Uppsala Conflict Data Program
	- Observed at event level in areas where more than 5 deaths occured in a given calendar year.
	- Downloaded from https://ucdp.uu.se/downloads/index.html#ged_global on January 6, 2023.
	- "GEDEvent_v22_1.csv" is the original csv file downloaded on violence.
	- "ucdp-actor-221.csv" is the original csv file downloaded on actors classified by type.

PRIO data:
	- Contains geographic and spatial data.
	- Observed at the grid-cell level for static variables, and grid-cell-year level for yearly data.
	- Downloaded from https://grid.prio.org/#/download on June 3, 2022.
	- "PRIO-GRID Static Variables - 2022-06-03.csv" is the original static CSV file
	- "PRIO-GRID Yearly Variables for 1999-2014 - 2022-06-03.csv" is the original yearly CSV file.
	- The "priogrid_cellshp" shapefiles were downloaded from https://grid.prio.org/#/extensions on June 3, 2022 and contain all of the shapefile information.

RADPKO data:
	- Contains data on peacekeeping operation deployments.
	- Observed at the grid-cell-month level.
	- Downloaded from https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/BQU5VD (version 4) on June 3, 2022.
	- "radpko_grid.csv" is the original CSV file downloaded.
